How to use

Drag a house, tree, flower bed, collectible, or pink player marker to its new place. Select a collectible to edit its icon, name, and wish.

Set the butterfly and rabbit counts in the toolbar.

The small labeled gate markers show each garden entrance on its branch road.

Select an object and click Delete selected to remove it. Use the add buttons to create more.

Click Save garden-layout.json and save over the project’s garden-layout.json. If it downloads instead, copy the downloaded file into the project before deploying to Netlify.

For local editing, start a web server in the project folder with python -m http.server 8000, then open http://localhost:8000/admin.html.
